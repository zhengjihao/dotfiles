# 1. What is this

Larry Darrell's dotfiles for Ubuntu 26.04 LTS Desktop. Currently, this repository contains only `.bash_aliases`.

# 2. How to Install

```bash
cd ~
git clone https://github.com/zhengjihao/dotfiles.git
cd ~/dotfiles
./install.sh
```

# 3. How to Use

To view all available aliases and functions, run:

```bash
cat ~/.bash_aliases
```
